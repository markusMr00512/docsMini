# DocsMini — ویرایشگر اسناد همکارانه

ویرایشگر اسناد همکارانه و لحظه‌ای با پشتیبانی کامل از فارسی و راست‌چین (RTL).
ساخته‌شده با Next.js 16، Prisma و Socket.io.

![Next.js](https://img.shields.io/badge/Next.js-16-black) ![TypeScript](https://img.shields.io/badge/TypeScript-5-blue) ![Tailwind](https://img.shields.io/badge/Tailwind-4-38bdf8) ![Prisma](https://img.shields.io/badge/Prisma-6-2d3748)

---

## ✨ قابلیت‌ها

### 🔐 احراز هویت امن
- توکن دسترسی JWT (۱۵ دقیقه) + توکن بازیابی چرخشی (۷ روز)
- تشخیص سرقت توکن (token reuse detection) — اگه یک توکن بازیابی استفاده‌شده دوباره ارائه شود، کل خانواده توکن‌ها ابطال می‌شود
- رمز عبور با bcrypt هش می‌شود
- کوکی httpOnly برای توکن بازیابی

### 📝 مدیریت اسناد
- ساخت، ویرایش و حذف اسناد
- داشبورد با نمایش عنوان، پیش‌نمایش محتوا و زمان آخرین ویرایش
- شمارش تعداد نسخه‌های هر سند

### ⚡ همکاری لحظه‌ای (Real-time)
- **حضور زنده**: آواتارهای رنگی همکاران به‌محض ورود به سند نمایش داده می‌شود
- **نشانگرهای زنده**: موقعیت نشانگر (cursor) هر همکار به‌صورت لحظه‌ای نمایش داده می‌شود
- **همگام‌سازی لحظه‌ای**: هر تغییر فوراً برای همه همکاران ارسال می‌شود
- **اتصال خودکار**: در صورت قطع اتصال، دوباره به‌صورت خودکار متصل می‌شود

### 📊 تاریخچه نسخه‌ها
- **ذخیره خودکار**: هر ۲.۵ ثانیه پس از توقف تایپ، یک نسخه ذخیره می‌شود
- **ذخیره دستی**: با دکمه «ذخیره» در هر زمان یک نسخه ایجاد کنید
- **پیش‌نمایش نسخه‌ها**: محتوای هر نسخه را قبل از بازیابی ببینید
- **بازیابی نسخه**: برگرداندن سند به یک نسخه قبلی (با ثبت نسخه جدید برای حفظ تاریخچه)
- نمایش نام نویسنده و زمان هر نسخه

### 🔗 اشتراک‌گذاری
- لینک اشتراک‌گذاری برای هر سند (`http://localhost:3000/#doc=<id>`)
- هر کاربر احراز‌هویت‌شده با لینک می‌تواند سند را باز کند

### 🇮🇷 پشتیبانی کامل از فارسی و RTL
- فونت **وزیرمتن** برای تایپوگرافی فارسی
- چیدمان راست‌چین کامل (RTL)
- تمام پیام‌های رابط کاربری و اعتبارسنجی به فارسی
- پشتیبانی از محتوای ترکیبی فارسی-انگلیسی

### 🎨 تجربه کاربری
- حالت روشن/تاریک (Dark mode)
- اسکلتون لودرها هنگام بارگذاری
- اعلان‌های Toast برای بازخورد عملیات
- طراحی واکنش‌گرا (Responsive)
- انیمیشن‌های Framer Motion
- میانبرهای کیبورد

## 🚀 راه‌اندازی پروژه

### مرحله ۱ — نصب وابستگی‌ها

در پوشه اصلی پروژه (جایی که `package.json` قرار دارد):

```powershell
npm install
```

### مرحله ۲ — پیکربندی فایل‌های محیط (.env)

دو فایل `.env` باید ساخته شوند:

```powershell
copy .env.example .env
copy mini-services\collaboration\.env.example mini-services\collaboration\.env
```

> **نکته مهم:** فایل `.env` اصلی باید شامل خط زیر باشد (به‌طور پیش‌فرض در `.env.example` وجود دارد):
> ```env
> NEXT_PUBLIC_COLLAB_URL=http://localhost:3003
> ```
> این متغیر به مرورگر می‌گوید که مستقیماً به سرویس همکاری روی پورت 3003 متصل شود. بدون این خط، اتصال لحظه‌ای کار نمی‌کند.

برای محیط تولید، رمزهای JWT قوی تولید کنید:
```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
# خروجی را در JWT_ACCESS_SECRET قرار دهید
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
# خروجی را در JWT_REFRESH_SECRET قرار دهید
```

### مرحله ۳ — راه‌اندازی پایگاه داده

```powershell
npm run db:push
```

این دستور فایل SQLite و تمام جداول (User، Document، DocumentVersion، ActiveCollaborator) را می‌سازد.

### مرحله ۴ — اجرای دو سرویس (در دو ترمینال جداگانه)

DocsMini از **دو سرویس** تشکیل شده که باید همزمان اجرا شوند:

**ترمینال ۱ — برنامه اصلی Next.js (پورت 3000):**
```powershell
npm run dev
```

**ترمینال ۲ — سرویس همکاری لحظه‌ای (پورت 3003):**

ابتدا یک بار `tsx` را نصب کنید (فقط اولین بار):
```powershell
cd mini-services\collaboration
npm install -D tsx
```

سپس سرویس را اجرا کنید:
```powershell
npx tsx watch index.ts
```

> `tsx` یک اجراکننده TypeScript برای Node.js است. `watch` باعث می‌شود با هر تغییر فایل، سرویس خودکار ری‌استارت شود.

### مرحله ۵ — باز کردن برنامه

مرورگر را باز کنید و به آدرس زیر بروید:

```
http://localhost:3000
```

## 🧪 راهنمای تست ویرایش همزمان

برای تست ویرایش همزمان، **دو کاربر باید همزمان وارد یک حساب کاربری شوند** و سند یکسانی را باز کنند. ساده‌ترین روش:

### روش ۱ — دو تب مرورگر با یک حساب (ساده‌ترین)

این روش برای تست سریع مناسب است:

1. در مرورگر به `http://localhost:3000` بروید
2. یک حساب کاربری بسازید (مثلاً نام: علی، ایمیل: ali@example.com)
3. روی **«سند جدید»** کلیک کنید و یک سند بسازید
4. ویرایشگر باز می‌شود — حالا روی **«اشتراک‌گذاری»** کلیک کنید (لینک کپی می‌شود)
5. یک **تب جدید** در همان مرورگر باز کنید (Ctrl+T)
6. لینک کپی‌شده را در نوار آدرس Paste کنید و Enter بزنید
7. حالا در هر دو تب سند باز است:
   - در تب اول چیزی تایپ کنید → فوراً در تب دوم ظاهر می‌شود
   - نشانگر (cursor) هر تب در تب دیگر به‌صورت یک خط رنگی نمایش داده می‌شود
   - نوار بالای ویرایشگر تعداد همکاران را نشان می‌دهد

### روش ۲ — دو پنجره مرورگر مختلف (پنجره ناشناس)

برای شبیه‌سازی دقیق‌تر دو کاربر:

1. یک پنجره مرورگر عادی باز کنید و وارد حساب شوید
2. یک سند بسازید و روی «اشتراک‌گذاری» کلیک کنید
3. یک **پنجره ناشناس (Incognito)** باز کنید (Ctrl+Shift+N در Chrome)
4. لینک را در پنجره ناشناس Paste کنید
5. با همان حساب کاربری وارد شوید (ایمیل و رمز عبور یکسان)
6. حالا در هر دو پنجره سند باز است و ویرایش همزمان کار می‌کند

### روش ۳ — دو مرورگر متفاوت

1. در Chrome وارد حساب شوید و سند را باز کنید
2. در Firefox (یا Edge) به `http://localhost:3000` بروید
3. با همان حساب وارد شوید و لینک سند را باز کنید
4. حالا در دو مرورگر ویرایش همزمان را تست کنید

### نشانه‌های کارکرد صحیح ویرایش همزمان

| نشانه | توضیح |
|-------|-------|
| 🟢 نشانگر **«متصل»** | اتصال Socket.io برقرار است |
| 👥 نمایش **«۲ همکار»** | هر دو تب/پنجره به‌عنوان همکار شناسایی شده‌اند |
| ✏️ تایپ لحظه‌ای | نوشتن در یک تب فوراً در تب دیگر ظاهر می‌شود |
| 📍 نشانگر رنگی | موقعیت cursor همکار با یک خط رنگی نمایش داده می‌شود |
| 💾 ذخیره خودکار | هر ۲.۵ ثانیه پس از تایپ، نسخه ذخیره می‌شود |

> **نکته:** برای دیدن تاریخچه نسخه‌ها، روی دکمه **«تاریخچه»** در بالای ویرایشگر کلیک کنید. می‌توانید نسخه‌ها را پیش‌نمایش و بازیابی کنید.

- **🔐 امنیت**: رمز عبور هرگز به‌صورت متن ساده ذخیره نمی‌شود، توکن‌های منقضی‌شده رد می‌شوند، سرقت توکن بازیابی شناسایی و خانواده توکن ابطال می‌شود
- **✅ اعتبارسنجی**: تمام ورودی‌ها با Zod اعتبارسنجی می‌شوند (ایمیل، طول رمز، عنوان، و...) با پیام‌های فارسی

> **نکته:** تست‌های API با Prisma **mock** شده اجرا می‌شوند — نیازی به پایگاه داده واقعی ندارند. تست سرویس همکاری یک سرور socket.io محلی روی پورت تصادفی راه‌اندازی می‌کند تا قرارداد رویدادها را تأیید کند.

## 🐛 رفع اشکال

### ویرایش همزمان کار نمی‌کند (نشانگر «آفلاین»)

1. **سرویس همکاری در حال اجراست؟** در ترمینال ۲ باید ببینید:
   ```
   Collaboration service listening on :3003
   ```
   اگه نیست، در `mini-services\collaboration` دستور `npx tsx watch index.ts` را اجرا کنید.

2. **متغیر `NEXT_PUBLIC_COLLAB_URL` تنظیم شده؟** در فایل `.env` اصلی این خط باید باشد:
   ```env
   NEXT_PUBLIC_COLLAB_URL=http://localhost:3003
   ```
   بعد از تغییر `.env`، حتماً `npm run dev` را ری‌استارت کنید (Ctrl+C و دوباره اجرا).

3. **رمزهای JWT یکسان‌اند؟** در هر دو فایل `.env` مقدار `JWT_ACCESS_SECRET` باید یکی باشد.

4. **بررسی در کنسول مرورگر:** دکمه F12 را بزنید، در تب Console تایپ کنید:
   ```js
   window.__collabTarget
   ```
   باید `"http://localhost:3003"` چاپ شود. اگه `/?XTransformPort=3003` بود، یعنی متغیر محیط بارگذاری نشده.

### خطای اتصال به پایگاه داده

- مطمئن شوید مسیر `DATABASE_URL` قابل نوشتن است
- `file:./db/custom.db` ایمن‌ترین گزینه است (نسبی به پوشه اصلی)

### پورت در حال استفاده است

- پورت 3000: در `package.json` تغییر دهید (`next dev -p 3001`)
- پورت 3003: در `mini-services/collaboration/index.ts` پورت را تغییر دهید و `NEXT_PUBLIC_COLLAB_URL` را به‌روز کنید

### تست دسترسی به سرویس همکاری

```powershell
curl.exe "http://localhost:3003/socket.io/?EIO=4&transport=polling"
```

اگه خروجی شبیه `0{"sid":"..."}` بود، سرویس در دسترس است. اگه «Failed to connect» بود، سرویس اجرا نمی‌شود یا فایروال مسدود می‌کند.

## 🔄 ارتقا به PostgreSQL

1. در `prisma/schema.prisma`:
```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

2. در `.env`:
```env
DATABASE_URL=postgresql://user:password@localhost:5432/docsmini
```

3. اجرای migrations:
```powershell
npm run db:migrate -- --name init
```
